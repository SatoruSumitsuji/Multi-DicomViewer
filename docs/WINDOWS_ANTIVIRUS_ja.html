Windows でウイルス対策ソフトに止められたときの対処

Multi-DICOMviewer（Windows版）を入れる・開くときに、ウイルス対策ソフトが

警告を出したり、ファイルを消してしまうことがあります。

まず安心してください。アプリは安全です。 これは「誤検知（ごけんち）」

といって、ソフトが念のため過剰に反応しているだけです。

なぜ起きるの？
このアプリには、メーカーが付ける「電子署名（＝身分証のようなもの）」が
まだ付いていません。署名のないアプリは、ウイルス対策ソフトが「念のため」
警告することがあります。中身は問題ありません。

下の3つのうち、あなたの画面に出ているものを探して、その手順どおりに

進めてください。

パターン①　ダウンロードした ZIP が開けない／展開できない

ダウンロードしたファイル（Multi-DicomViewer-windows.zip）を展開する前に、

「ブロックの解除」をすると、うまくいくことが多いです。

  1. ダウンロードした ZIP ファイルを右クリックします。
  2. メニューの一番下の 「プロパティ」 をクリックします。
  3. 開いた小窓の下のほうに

「セキュリティ：このファイルは…ブロックされています」 という文があれば、

その右の 「許可する」 にチェックを入れます。

  • ※この文が無ければ、そのまま 4 に進んでOKです。
  1. 「OK」 を押します。
  2. そのあとで、ZIP を展開（解凍）します。

（ZIP を右クリック →「すべて展開」）

ポイント：すでに展開したものがある場合は、いったん削除してから、
上のやり方で「ブロックの解除」をした ZIP を展開し直すのが確実です。

パターン②　起動時に青い画面で「Windows によって PC が保護されました」

これは Windows の標準機能（SmartScreen）の警告です。

  1. 青い画面の中の 「詳細情報」 という小さな文字をクリックします。
  2. すると下に 「実行」 ボタンが出てくるので、それをクリックします。

これでアプリが起動します。次回からは出なくなります。

パターン③　ファイルが消えた／「ウイルスを検出しました」と出た

ウイルス対策ソフトがアプリのファイルを隔離（かくり）した状態です。

アプリのフォルダを「例外（除外）」に登録して、復元します。

Windows 標準（Windows セキュリティ / Defender）の場合

  1. 画面左下の スタート（旗のマーク）を押し、「セキュリティ」 と入力 →

「Windows セキュリティ」 を開きます。

  1. 「ウイルスと脅威の防止」 をクリックします。
  2. 「設定の管理」 をクリックします。
  3. 下のほうの 「除外の追加または削除」 をクリックします。
  4. 「除外の追加」→「フォルダー」 を選び、

展開した 「Multi-DicomViewer」フォルダを指定します。

  1. もしファイルが消えていたら、同じ「ウイルスと脅威の防止」の画面で

「保護の履歴」 を開き、Multi-DicomViewer の項目を選んで

「許可」 で元に戻します。

  1. 必要なら、もう一度 ZIP を展開し直してください。

ウイルスバスター等、他社のソフトの場合

考え方は同じです。そのソフトの設定の中にある

「例外設定」「除外リスト」「信頼するプログラム」 などに、

「Multi-DicomViewer」フォルダを追加してください。

（メニュー名はソフトによって少し違います）

大事なコツ

  • アプリは フォルダごと（中身を全部まとめて）扱ってください。

中の Multi-DicomViewer.exe だけを取り出さないでください。

  • ZIP の中から直接起動しないでください。必ず展開してから開きます。

それでも開けないときは

無理をせず、このアプリを渡してくれた人（配布元）に連絡してください。

お使いのウイルス対策ソフトの名前（例：「ウイルスバスター」「ノートン」など）を

伝えていただけると、そのソフトに合わせた手順をご案内できます。
