# Multi-DICOMviewer 使い方説明書

研究・教育用のマルチモダリティ DICOM ビューアです。**XA アンギオ（心臓カテーテルのシネ）**、
**心臓 CT（CCTA）**、**IVUS**、その他（US/NM/OCT/OFDI 等）の DICOM を表示・計測・書き出しできます。

> ⚠️ **本ソフトは医療機器ではありません。** 研究・教育目的のみで、臨床診断には使用しないでください。

対応バージョン: 1.2.0 時点の機能で記載しています。

## 1. 起動方法

### Windows
配布zip（`Multi-DicomViewer-windows.zip`）を展開し、`Multi-DicomViewer.exe` をダブルクリックします。

### macOS
配布zip（`Multi-DicomViewer-macos.zip`）を展開し、`Multi-DicomViewer.app` を「アプリケーション」へ移動します。
**初回のみ**、アプリは未署名のため Gatekeeper にブロックされます。ターミナルで次の1行をコピー＆ペーストして実行してから起動してください（ドラッグ&ドロップ不可、コピペで実行）:

```bash
{ find /Applications ~/Applications ~/Downloads -maxdepth 2 -name "Multi-DicomViewer.app" -print; mdfind -name "Multi-DicomViewer.app"; } | sort -u | while read -r p; do xattr -dr com.apple.quarantine "$p"; done
```

以降は通常どおりダブルクリックで起動します。

## 2. 画面構成

```
┌──────────────┬──────────────────────────────────────┐
│              │  メニューバー（File / View / Tools）     │
│  スタディ      │  レイアウトボタン・Bi/Lt/Rt ボタン        │
│  ブラウザ      ├──────────────────────────────────────┤
│  （左ドック）   │                                      │
│              │      ビューワペイン（1〜4面）            │
│  Tree /      │   CTは左、XA/IVUSは右に置くと比較しやすい  │
│  Thumbnails  │                                      │
└──────────────┴──────────────────────────────────────┘
                    最下部：ステータスバー
```

- **左のスタディブラウザ**: 患者 ▸ スタディ ▸ シリーズの一覧。
- **右のビューワペイン**: シリーズを表示。レイアウトで1〜4面に分割可能。
- 同じ患者の **CT と XA を左右に並べて対比** できるのが本アプリの特徴です。

## 3. データの読み込み

- **メニュー: File ▸ Open DICOM folder…**（`Ctrl+O`）でフォルダを選択。サブフォルダも再帰的にスキャンします。
- フォルダを **ビューワ領域へドラッグ&ドロップ** しても読み込めます。
- 起動時にフォルダパスを引数で渡すこともできます（コマンドライン起動時）。
- **File ▸ Clear viewers**: 表示中のビューワをクリア。

読み込み後、ブラウザに 患者 ▸ スタディ ▸ シリーズ がツリー表示されます。

---

## 4. スタディブラウザ

### 表示の切り替え
- **📋 Tree**: 患者/スタディ/シリーズのツリー表示（日時・シリーズ番号・種別・画像数・説明・ファイルパス）。
- **🖼 Thumbnails**: 選択中スタディのシリーズをサムネイル表示。右下のスライダーでサムネイルサイズを変更。
- Tree と Thumbnails は選択が連動します。

### マーク・表示
- 患者名の横の **`⚹ CT+XA`**: その患者が CT と XA の両方を持つ目印。
- スタディは **モダリティ種別ごとに別ノード**で表示されます（同じ検査日でも XA と OT は別行）。
- 列ヘッダ（Date/Time・Series No・Instance No・Images）クリックで、**選択中スタディのみ**並べ替え。

### ボタン
- **Anonymous**: 患者名・ID・日付など個人情報を画面上で伏せ字表示（ファイルは変更されません。メニュー `View ▸ Anonymize` / `Ctrl+Shift+A` と同じ）。
- **DICOM Info**: 画像上の DICOM タグ文字オーバーレイの表示/非表示。

### 操作
- シリーズをクリック → アクティブなペインに表示。
- スタディ行をクリック → そのスタディで**最後に見ていたシリーズ**を再表示（無ければ先頭）。
- シリーズを **ペインへドラッグ&ドロップ** → そのペインに表示。
- **右クリックメニュー**:
  - **Export (DICOM)**: 元の .dcm を無劣化コピー。
  - **Export (MP4)**: シネを MP4 に書き出し（ビットレート/FPS 指定可）。
  - **Close**: シリーズ一覧を畳む。
  - **Delete (remove from list)**: 一覧から除外（ファイルは削除されません）。
  - `Ctrl`/`Shift`+クリックで複数選択 → まとめて書き出し/削除。

## 5. 画面レイアウト

上部のレイアウトボタンでペイン数を切り替えます:

| ボタン | 構成 |
|------|------|
| **1×1** | 1面（全画面） |
| **1×2** | 横2面 |
| **2×1** | 縦2面（各行フル幅） |
| **2×2** | 4面 |

- **Bi / Lt / Rt ボタン**: バイプレーン XA や2面 CT の表示切替。
  - **Bi**: 両方表示（1×1・2×1 ではバイプレーンを Front+Lateral 並べて表示）
  - **Lt**: 左（プレーン0）のみ
  - **Rt**: 右（プレーン1）のみ
- ペインのタイトル部を **ドラッグして他ペインと位置入れ替え** が可能です。

## 6. アンギオ / IVUS ビューワ

XA（アンギオ・シネ）と IVUS は共通の操作系です。

### 6-1. シリーズ送り（上段ツールバー）
- **⏮ First / ◀ Prev (A) / ▶ Next (F) / ⏭ Last**: 同一モダリティ内のシリーズ移動。

### 6-2. 再生（トランスポート）
- **▶ Play / ⏸ Pause**: シネ再生・一時停止。
- **シークバー**: フレーム位置の移動。つまみは「白丸＋大きい青ドット」。
- **fps**: 再生速度（フレーム/秒）。
- **XXX/XXX（フレーム数表示）**: 現在/総フレーム。**クリックで再生範囲を全域にリセット**。

#### 再生範囲（開始点・終了点）
- シークバーの**上**に、青い**下向き三角マーカー2つ**（開始点・終了点）があります。
- ドラッグで範囲を指定すると:
  - **再生**・**シーク（つまみ移動）**がその範囲内に制限されます。
  - **MP4 書き出し**がその範囲のみになります（**DICOM 書き出しは仕様上つねに全フレーム**）。
- **フレーム数表示をクリック**すると範囲が全域に戻ります。

### 6-3. ウィンドウ/レベル（W/L）— `W` キー
- `W` キー（または画像の右クリック ▸ Change W/L）で **W/L 調整ポップアップ**を開きます。
- ポップアップの **W**（幅）・**L**（レベル）スライダーで濃淡を調整。つまみは「白丸＋小さい青ドット」。
- カラー画像（RGB シネ）では W/L は無効です。

### 6-4. 心電図（ECG）表示 — `V` キー（アンギオ）
- アンギオ（XA）表示中に `V` キーで、画像の下に **心電図波形ストリップ**を表示/非表示。
- （IVUS 表示中は `V` は長軸表示の切り替えになります。モダリティで自動的に切り分けられ、競合しません。）
- DICOM の Waveform Sequence または レガシー Curve Data から波形を読み取り、**再生フレームに同期した黄色いカーソル**が動きます。
- 波形を含まないシリーズでは表示されず、「心電図データはありません」と通知します。

### 6-5. 計測ツール
- **📏 Measure** をオンにすると計測バーが出ます: **Line（距離）/ Polyline / Ellipse / Polygon / Angle（角度）/ Clear**。
- 左クリックで点追加、Polyline/Polygon は**右クリックで確定**。
- `ImagerPixelSpacing` を持つシネは **mm 表示**、無ければ **ピクセル表示**。
- **Measure History**: そのスタディの計測履歴を表示。

### 6-6. 拡大（ズーム）
- **🔍+ / 🔍−**: クリックした点を中心に拡大/縮小（×1.1 / ×0.9）。**🔍1** で元に戻す。
- キー: `Z`（拡大）/ `Shift+Z`（縮小）。

### 6-7. DICOM タグ表示
- **DICOM Tags…**: 画像に重ねる DICOM タグ項目を選択。上のスライダーで文字サイズ調整（全ビューワ共通）。
- `Q` キーでオーバーレイの表示/非表示。

### 6-8. IVUS 長軸（ロングアクシス）— `V` キー（IVUS）
- IVUS 表示中に `V` キー、または **Long View** ボタンで、断面像の下に**長軸（縦切り）画像**を表示。
- （`V` はアンギオ表示中は心電図、IVUS 表示中は長軸、とモダリティで切り替わります。）
- **通常の横方向ドラッグ**で長軸画像の**幅のみ**を拡大/縮小（高さは枠に自動フィット）。
- **Shift+縦方向ドラッグ**で回転（カテーテル軸まわり）。
- 断面像上の**回転中心マーカー**をドラッグして、各フレームの中心を指定（キーフレーム）。
  - **◀ Center / Center ▶**: 中心を設定したフレーム間をジャンプ。
  - **Clear Centers**: その面の手動中心をすべて消去。
- 長軸画像も右クリックで静止画書き出し可能。

### 6-9. 静止画書き出し
- 画像上で**右クリック** → PNG / JPEG / TIFF で保存（計測線やタグ文字も含めた表示のまま＝WYSIWYG）。

## 7. CT ビューワ

CT は直交/斜め MPR（多断面再構成）で表示します（Windows は VTK、macOS は pygfx/Metal）。

### 7-1. 表示
- 軸位・冠状・矢状などの **2面 MPR**＋クロスヘア連動。
- 各面のスライススライダーでスライス送り。
- 画像を**ダブルクリック**でその位置に再センタリング。

### 7-2. ツール（ツールバー or ショートカット）
マウス操作のモードを切り替えます:

| キー | ツール | 機能 |
|----|------|------|
| `Z` | ZOOM | 拡大縮小 |
| `V` | MOVE | 移動（パン）/ クロスヘア移動 |
| `R` | ROTATE | 斜め断面の回転 |
| `S` | SPIN | 面内回転 |
| `G` | PAGING | スライス送り |
| `T` | THICK | スラブ厚（厚み付き MIP）の変更 |
| `W` | WL | ウィンドウ/レベル調整 |
| `C` | （色） | HU カラーマップの ON/OFF |

- **HU プリセット**: 冠動脈 / 縦隔 / 肺 / 骨 などのウィンドウ/レベルを切り替え可能。
- **計測**: Line / Polyline / Ellipse / Polygon / Angle（XA/IVUS と共通の計測モデル、Measure History に記録）。
- `Q` キーで DICOM タグオーバーレイの表示/非表示。

### 7-3. macOS 固有 — スラブ表示の高解像度化
- スラブ（厚み付き）MPR は、操作中（ドラッグ/回転/ホイール送り）は**低品質**で滑らかに描画し、止めると自動で高品質に戻ります。
- もし粗いままの場合:
  - **右クリックのシングル** = 静止画書き出し
  - **右クリックのダブル** = 高解像度（フル品質）に再構築
- （Windows 版はつねにフル品質のため、この区別はありません）

## 8. ツールメニュー（解析機能）

メニュー **Tools** から各解析を開きます。

- **MultiSync IVUS viewer…**: 複数ペインの IVUS を**同期シークバー**で並べて再生・比較。同期ポイント設定、高品質 MP4 書き出しに対応（1×2 / 2×1 / 2×2 レイアウトで利用可）。
- **Rupture-Predictor…**: 伸展比（stretch-ratio）ベースの解析ツール（ネイティブ版）。
- **Orthogonal-View…**: アクティブな XA 画像でベクトルを指定すると、それに**直交する視野の C アーム角度**（LAO/RAO・CRA/CAU）を算出（C アーム角度を持つ XA 表示時に利用可）。
- **Coaxial Eval…**: 2つ以上のアンギオ視野で同じ血管上にラベル付きの線（GC / proxLAD など）を引き、**3次元の GC–血管角度**を算出（C アーム角度を持つ XA 表示時に利用可）。

## 9. 書き出し（エクスポート）

| 種類 | 操作 | 内容 |
|----|------|------|
| **DICOM** | ブラウザで右クリック ▸ Export (DICOM) | 元 .dcm を無劣化コピー。ファイル名は選んだフィールドから生成。**つねに全フレーム**。 |
| **MP4** | ブラウザで右クリック ▸ Export (MP4) | シネを MP4 に。ビットレート/FPS 指定可。**再生範囲マーカーで絞った範囲のみ**書き出し。 |
| **静止画** | 画像上で右クリック ▸ 形式選択 | PNG / JPEG / TIFF。表示そのまま（計測・タグ込み）。 |

- DICOM タグオーバーレイの設定は **View ▸ Export/Import DICOM tag overlay settings…** で保存・読み込みできます。

## 11. トラブルシューティング

### Windows: 展開後に exe が消える / 起動できない
- ウイルス対策ソフト（Windows Defender や **ウイルスバスター**等）が、署名のない実行ファイルを**誤検知して隔離**することがあります。アプリ自体は無害です。
- **対処**: ウイルス対策ソフトの**例外（除外）設定**にアプリのフォルダ（`Multi-DicomViewer` フォルダ）を追加し、**zip を展開し直して**ください。
- 恒久対策として、各社への**誤検知の再評価依頼**（無料）も可能です。

### macOS: 「壊れている/開発元を確認できない」で開けない
- 上記 [1. 起動方法](#1-起動方法) の **xattr コマンド**を1回実行してください。

### CT が表示されない
- CT 描画には依存ライブラリ（Windows: VTK / macOS: pygfx）が必要です。配布ビルドには同梱済みです。CT ペインにエラーが出る場合はその内容を確認してください。
